01

Frontend Client-side

Build user interfaces that run in the browser.

UI
FE / 01

React

Single-page apps, large dynamic web apps, and flexible UI development.

Where it fits

A broad component ecosystem suits interactive products and teams that want flexibility in how they structure an application.

FE / 02

Angular

Enterprise applications, large teams, and structured development.

Where it fits

A comprehensive, convention-led toolkit can help larger teams build and maintain complex applications consistently.

FE / 03

Vue.js

Small to medium apps, quick setup, and an approachable learning curve.

Where it fits

Progressive adoption makes Vue useful for focused interfaces as well as complete browser applications.

02

Backend Server-side

Handle business logic, APIs, and database operations.

API
BE / 01

Node.js (Express)

Real-time services, REST APIs, and JavaScript backend development.

Where it fits

A JavaScript server runtime with a lightweight web framework works well for APIs and event-driven services.

BE / 02

Django

Secure, database-driven products and content-heavy websites.

Where it fits

Its batteries-included approach supports rapid delivery of data-rich applications with common features built in.

BE / 03

Spring Boot

Enterprise applications and large-scale systems in the Java ecosystem.

Where it fits

A mature Java ecosystem and strong production tooling make it a common choice for long-lived services.

BE / 04

Laravel

Web apps, e-commerce, CMS, and PHP-based development.

Where it fits

Expressive conventions and an extensive package ecosystem help teams build PHP applications efficiently.

03

Full-stack Frontend + backend

Build the user experience and server features together.

↗
FS / 01

Next.js

Modern web apps with server rendering and SEO-friendly pages.

Where it fits

React-based routing and rendering options support content-rich sites and interactive web products.

FS / 02

Nuxt.js

Vue-based full-stack apps and static site generation.

Where it fits

A structured Vue framework offers server rendering, static output, and conventions for full-stack projects.

FS / 03

SvelteKit

High-performance web apps and a streamlined development experience.

Where it fits

Svelte's compiler-led approach and integrated routing can suit lean, fast web experiences.

FS / 04

Remix

React full-stack applications focused on web standards.

Where it fits

Web-native forms, loading patterns, and nested routes make it useful for data-driven user experiences.

04

Mobile apps iOS + Android

Build mobile experiences for both major platforms.

MOB
MO / 01

React Native

Cross-platform mobile apps using JavaScript and React.

Where it fits

Share application logic across platforms while building interfaces with native platform components.

MO / 02

Flutter

Cross-platform apps with a consistent, custom user interface.

Where it fits

A shared UI toolkit can help deliver polished experiences across mobile platforms from one codebase.

MO / 03

Ionic

Hybrid mobile apps built with familiar web technologies.

Where it fits

Web skills and reusable UI components can be a practical fit for cross-platform apps and web teams.

05

Static site generators Fast + lightweight

Publish fast websites with minimal server-side processing.

SSG
SS / 01

Gatsby

React-based static sites and content-driven experiences.

Where it fits

Useful for content sites that benefit from pre-rendered pages and a React development model.

SS / 02

Hugo

Very fast static sites, documentation, and publishing.

Where it fits

A fast build pipeline makes Hugo practical for large content collections and documentation sites.

SS / 03

Jekyll

Simple static websites and blogs with a long-standing ecosystem.

Where it fits

Markdown-friendly publishing and GitHub Pages support suit straightforward sites and project documentation.

06

Content management CMS

Create and manage content with minimal coding.

CMS
CM / 01

WordPress

Flexible publishing, business websites, and online stores.

Where it fits

A large plugin and theme ecosystem supports a wide range of content-led sites and editorial workflows.

CM / 02

Drupal

Structured content platforms with detailed permissions and workflows.

Where it fits

Granular roles and content modeling suit complex publishing operations and multi-team sites.

CM / 03

Strapi

Headless content management for custom digital experiences.

Where it fits

Deliver content through APIs to websites, apps, and other frontends while managing it in one place.

07

E-commerce Online stores

Build, manage, and grow online shopping experiences.

SHOP
EC / 01

Magento

Feature-rich commerce for complex catalogs and store operations.

Where it fits

Extensive customization and commerce capabilities can serve larger or more complex retail requirements.

EC / 02

Shopify

Hosted commerce for launching and operating online stores.

Where it fits

A managed platform and app ecosystem help teams focus on merchandising, customer experience, and growth.

EC / 03

WooCommerce

WordPress-based stores with flexible product and content options.

Where it fits

Combines WordPress publishing with configurable product, checkout, and store management features.

08

Real-time applications Live updates

Keep users and systems in sync as data changes.

LIVE
RT / 01

Socket.IO (Node.js)

Bidirectional events for live web experiences and collaboration.

Where it fits

Useful for chat, live dashboards, collaboration, and other experiences needing low-latency updates.

RT / 02

Firebase

Managed backend services for apps with synchronized data.

Where it fits

Hosted data, authentication, and app services can accelerate prototypes and real-time product features.

RT / 03

SignalR (.NET)

Real-time communication for .NET applications.

Where it fits

Integrates real-time connections into .NET apps for notifications, live dashboards, and collaboration.
